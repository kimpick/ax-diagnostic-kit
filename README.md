# ax-diagnostic-kit

AI 활용 역량(AX) 진단을 실행하는 플랫폼입니다.

시중 진단 상품들을 직접 응시·분석한 뒤, **"AI를 안다"가 아니라 "AI로 일할 수 있다"를 측정하려면 도구가 어떻게 생겨야 하는가**에 대한 답으로 만들고 있습니다.

> 🚧 초기 개발 단계입니다. 아직 동작하는 애플리케이션이 없습니다.

## 설계 관점

- **문항은 데이터, 플랫폼은 런타임** — 문항·루브릭·시나리오는 버전이 찍힌 데이터이고, 런타임은 그것을 해석해 실행할 뿐입니다. 새 문항 유형을 추가할 때 런타임을 고쳐야 한다면 그건 틀이 아닙니다.
- **응시 시점의 정의를 스냅샷으로 고정** — 문항이나 루브릭을 나중에 바꿔도 과거 응시자의 점수를 재현할 수 있어야 합니다.
- **채점은 재현 가능해야 한다** — 점수와 함께 사용한 모델·프롬프트 버전·루브릭 버전·판정 회차별 원점수를 모두 남깁니다. "왜 이 점수인가"에 답할 수 없는 진단은 쓸 수 없습니다.

## 구성 (예정)

| 영역 | 선택 |
|---|---|
| 앱 | Next.js (App Router) + TypeScript |
| DB·인증 | Supabase (Postgres + Google OAuth) |
| LLM | Google Gemini (실기 챗봇 / 채점에 각각 다른 등급) |
| 배포 | Vercel |
